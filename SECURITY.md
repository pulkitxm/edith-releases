# Security

Please report vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/pulkitxm/edith-releases/security/advisories/new).
Do not open a public issue, discussion or comment about it.

Include the Edith version (`ed version`), the extension and its version if one
is involved, your macOS version, what an attacker can do and the steps to
reproduce it. You will get a reply within a few days, and a fix ships as a
signed release in this repository.

Only the latest release is supported.
